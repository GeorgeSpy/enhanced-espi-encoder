# Enhanced ESPI Encoder

This repository contains the evaluation code, frozen-feature extraction tools, and diagnostic scripts for auditing ESPI (Electronic Speckle Pattern Interferometry) representations. The primary focus is on grouped specimen-level (Board LOBO) and material-level (Material LOMO) robustness of image-derived encoders.

## Project Structure
- `src/`: Core Python modules for the ESPI encoder and feature evaluation schema.
- `scripts/encoder/`: Executable scripts for running evaluations, extracting features, generating class-level diagnostics, and creating publication-ready tables and figures.
- `reports/`: Markdown reports and figures generated by the evaluation scripts.
- `docs/`: Additional documentation and ablation plans.

## Features
- **Frozen-Encoder Auditing:** Evaluates frozen representations (v6.1, v6.2-A, ResNet-18 baselines) using fixed-$k$ kNN, linear probes, and prototype classifiers.
- **Grouped Protocols:** Rigorous Leave-One-Board-Out (LOBO) and Leave-One-Material-Out (LOMO) cross-validation splits.
- **Information-Budget Controls:** Frequency-only baseline prediction and frequency+embedding fusion to control for the physical correlation between modal patterns and excitation frequency.
- **Targeted Overlap Analysis:** Evaluates the capacity of embeddings to resolve structural ambiguity in frequency-overlapping modes (e.g., 1_2 vs 2_1).
- **Statistical Hardening:** Paired Wilcoxon, paired t-test, Cohen's d, and paired bootstrap scripts for robust fold-level comparisons.
