# Reproducibility Notes

This repository contains lightweight code and report summaries only.

## Included

- encoder extraction/audit scripts
- v6.2 model/training scripts
- v6.2 config snapshots
- summary reports for baseline comparison and encoder evaluation

## Excluded

- raw ESPI images
- acoustic measurements
- checkpoints
- feature dumps
- full confusion-matrix folders
- large logs

## Result Traceability

Each publishable result should map to:

```text
script -> config -> artifact reference -> report summary
```

Before public release, the exact commands and artifact hashes must be added.
